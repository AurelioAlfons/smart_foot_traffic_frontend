## 📖 About

Smart Foot Traffic Monitoring System is a Flutter web application built to help users analyse pedestrian traffic data through an interactive dashboard.

Users can filter traffic data by date, time, traffic type, year, and season, then generate visual insights such as heatmaps, charts, forecasts, and detailed sensor snapshots.

The project was built as part of a larger foot traffic monitoring system, with the Flutter frontend communicating with a Flask backend API to retrieve and process traffic data.

---

## ✨ Core Features

* **Traffic Filtering** — Filter data by date, time, traffic type, year, and season.
* **Heatmap Visualisation** — View foot traffic intensity across different sensor zones.
* **Interactive Charts** — Analyse traffic using bar, line, pie, and forecast charts.
* **Traffic Snapshots** — Display detailed traffic information for individual sensor zones.
* **Forecasting** — Visualise predicted traffic patterns using processed backend data.
* **Report Exporting** — Generate and download an HTML report containing traffic insights.

---

## ⚙️ How It Works

The **Flutter Web** frontend provides the main dashboard and user interface.

Users select traffic filters and submit a request to the **Flask backend API**, which retrieves and processes the relevant traffic data.

The returned data is then used by the frontend to generate heatmaps, traffic snapshots, charts, and forecast visualisations.

The application separates its UI, data-processing logic, reusable widgets, and visualisation tools to keep the project organised and easier to maintain.
